# tLib — библиотека отчётов о спортивных туристских походах

Веб-приложение для публикации и поиска отчётов о спортивных туристских
походах: полнотекстовый и параметрический поиск по базе SQLite, просмотр
ZIP-архивов и PDF прямо в браузере без скачивания, поддержка GPS-треков
(GPX, KML, KMZ, GeoJSON), приём новых отчётов через панель загрузки.

Публичный экземпляр: [tlib.ru](https://tlib.ru).

## Технологии

- **Backend** — Python (FastAPI) + SQLite. Слои строго разделены:
  `middlewares/` → `routers/` → `services/`.
- **Frontend** — vanilla JavaScript (ES6-модули), без внешних CDN и
  npm-зависимостей в рантайме.
- **Хранение файлов** — новые отчёты проходят пайплайн File Watcher
  (`services/file_watcher/`) с валидацией и бэкапом перед публикацией.

Подробности — в [doc/ARCHITECTURE.md](doc/ARCHITECTURE.md).

## Что не входит в репозиторий

Каталоги `data/`, `data.*/` (включая `data.secret/` с базой пользователей и
SMTP-настройками) в репозиторий не входят и создаются приложением при
первом запуске — см. [doc/DEPLOY.md](doc/DEPLOY.md).

распространяется под лицензией **GNU AGPL-3.0**. При включении этой функции

требованию предоставлять исходный код пользователям сетевого сервиса;

закрытого использования PyMuPDF нужна отдельная коммерческая лицензия
[Artifex](https://artifex.com/licensing).
